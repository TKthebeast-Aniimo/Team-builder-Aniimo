# Aniimo Team Builder

Unofficial fan-made Aniimo team-building and synergy analysis site.

## Features

- 4-slot team builder
- No forced role composition
- DPS / Support / Regen / Break / Heal
- Search and filter by role and element
- Aniimo portraits when the source publishes a usable image
- Base stats, skills, traits and forms
- Explainable synergy scoring
- Elemental weakness warnings
- Suggested team game plan
- Automatic weekly data refresh from the Official Aniimo Wiki

## Data philosophy

The official Aniimo Wiki is the primary factual source. Aniidex is a secondary reference. The site does not treat its generated team score as official game information.

Game data can change before and after launch. Run the refresh workflow after patches.

## GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose your main branch and `/ (root)`.
5. Save.
6. Wait for GitHub to publish the site.

## Refresh data manually

GitHub → Actions → Refresh Aniimo data → Run workflow.

The weekly schedule will also refresh automatically.

## Portraits and game assets

The site references portrait URLs exposed by the source site rather than claiming ownership of game artwork. If a source does not permit hotlinking or redistribution, the portrait may not display. Do not remove source/ownership notices.
